# Cybersecurity Portfolio - Terminal Style

A modern, responsive cybersecurity portfolio built with React (frontend) and Express.js (backend). Features a terminal-style interface with interactive command navigation.

## 🎯 Features

- **Terminal-Style UI**: Command-based navigation with `/help` support
- **Full-Stack Application**: React frontend + Express.js backend
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Interactive Terminal**: Built-in command interface
- **Project Showcase**: Display your projects with tech stack details
- **Skills & Certifications**: Showcase your expertise and credentials
- **Contact Form**: Functional contact messaging system

## 📋 Prerequisites

- Node.js 14+ 
- npm or yarn
- Git

## 🚀 Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/PRASAD2410/PORTFOLIO.git
cd PORTFOLIO
```

### 2. Install Dependencies

**Frontend:**
```bash
cd frontend
npm install
```

**Backend:**
```bash
cd backend
npm install
```

### 3. Run Development Servers

**Backend (Terminal 1):**
```bash
cd backend
npm run dev
# Server runs on http://localhost:5000
```

**Frontend (Terminal 2):**
```bash
cd frontend
npm run dev
# Server runs on http://localhost:3002
```

## 🎮 Available Commands

In the terminal interface, use these commands to navigate:

```bash
/home          - Navigate to home page
/about         - View about section
/skills        - See technical skills
/projects      - Browse your projects
/education     - View education
/experience    - Check internship/work experience
/awards        - View achievements
/contact       - Contact form
/clear         - Clear terminal history
/help          - Show all commands
/whoami        - Display portfolio info
```
